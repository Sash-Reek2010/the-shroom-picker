# The Shroom Picker
This is a tiny game about picking up mushrooms in the forest and caves as a weird green haired, blue skinned person!

## Features
You can pick up mushrooms and keep track of how many you've collected! There's 2 biomes to explore and 4 kinds of collectible mushrooms!
